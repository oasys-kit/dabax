========
Examples
========

Examples are available in the ``examples/`` directory of the
`repository <https://github.com/oasys-kit/dabax/tree/main/examples>`_:

* `dabax_examples.py <https://github.com/oasys-kit/dabax/blob/main/examples/dabax_examples.py>`_ —
  Basic usage of the dabax API
* `dabax_examples_xraylib_api.py <https://github.com/oasys-kit/dabax/blob/main/examples/dabax_examples_xraylib_api.py>`_ —
  Using dabax with the xraylib-compatible API
* `refraction_index.py <https://github.com/oasys-kit/dabax/blob/main/examples/refraction_index.py>`_ —
  Computing refraction indices

See also :doc:`sign_conventions` for the time convention of the complex quantities
(``Fii``, ``Refractive_Index``, structure factors) returned by these functions.
